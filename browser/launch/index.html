Run the local web app¶

Install Netbone in your Python environment, then run either of these commands.

netbone-web

python -m netbone.webapp

Open 127.0.0.1:8765 in a browser on the same machine. Keep the terminal open while you work. Press Ctrl+C there to stop the server. The installed distribution includes the browser assets. A separate frontend build is only needed when developing the UI.

Startup options¶

netbone-web --help lists both startup settings.

Option Default Purpose
--host 127.0.0.1 Address where the local server listens
--port 8765 TCP port

If the default port is occupied, choose another local port.

netbone-web --port 8766

Then open 127.0.0.1:8766.

Where data is processed¶

The browser sends the network to the local Python process for analysis. The server keeps recent scores, results and export handles in memory. Download files you want to retain before leaving the session. Restarting the server clears its caches.

The supported setup is loopback on your own machine. The bundled server has no authentication or TLS and there is no supported hosted deployment. The app uses local HTTP routes for previews, analyses, and downloads. Their request formats and cached IDs belong to the browser implementation. Use the Python API for scripted analysis.

Continue with the browser tutorial or import your own network.
