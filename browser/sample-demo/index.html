Try the web demo¶

Explore Zachary’s Karate Club, a real network of 34 members and 78 links. Edge weights count the contexts in which two members interacted.

Open the web demo

Compare two 20-edge backbones¶

The demo opens with Edge Weight at 25% retention. Compare already contains two saved backbones at this edge budget.

  1. Run the comparison and select Overlap & agreement, then Shared edges.
  2. Check the 6 shared links. Each method kept 20 links, with 14 selections unique to each method.
  3. Return to the network preview. Change method to see how weighted Edge Betweenness brings a different set of links into the graph.
  4. Choose 50% to see what changes when the edge budget grows.

Edge Weight ranks ties by their observed strength. Edge Betweenness ranks them by how often they lie on shortest paths, treating higher weights as shorter distances. Both use a stable tie rule to keep the same number of links.

The demo loads precomputed Netbone results, including the statistics and downloads, for this dataset and its available settings. Use the local web app to import your own file.

Open Inspect & export to explore the method statistics, download run settings, or export a graph or experiment ZIP. Use Copy BibTeX in the footer to copy the Netbone citation.
