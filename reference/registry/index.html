Registry discovery and lower-level helpers¶

Use the top-level registry functions to discover available methods and filters and inspect their metadata. For direct calls, the helpers shown below operate on normalized networks or computed method results. Most workflows can use netbone.score(), netbone.filter_scores(), or a pipeline.

list_methods() ¶

Return registered built-in method names.

describe_method(name) ¶

Return JSON-compatible metadata for a registered method.

list_filters() ¶

Return registered built-in filter names.

describe_filter(name) ¶

Return JSON-compatible metadata for a registered filter.

Scorers exported by netbone.methods¶

compute_disparity(network, *, weight='weight', pvalue_aggregation='min', leaf_policy='ignore') ¶

Compute edge p-values from the disparity filter.

For each endpoint of an edge, the method computes the fraction of that endpoint's strength carried by the edge, then evaluates the disparity null model p-value (1 - fraction) ** (degree - 1). Endpoint p-values are combined into the method-specific primary statistic disparity_pvalue. For a directed arc, the source value uses its outgoing distribution and the target value uses its incoming distribution.

Parameters:

Name Type Description Default
network Network

Normalized simple directed or undirected network to score.

 required
weight str

Edge attribute containing finite positive weights.

 'weight'
pvalue_aggregation str

How to combine endpoint p-values: min, max, or average.

 'min'
leaf_policy str

How degree-one endpoints contribute: ignore ignores them during aggregation when another endpoint is available, while zero uses the previous behavior where leaf endpoint p-values are 0.0.

 'ignore'

Raises:

Type Description
ConfigurationError

If a method parameter value is invalid.
ValidationError

If a required weight is missing, non-numeric, non-finite, zero, or negative.

compute_lans(network, *, weight='weight', pvalue_aggregation='min', leaf_policy='zero') ¶

Compute LANS empirical upper-tail p-values for each edge.

For undirected graphs, LANS compares an edge's fractional incident weight at both endpoints and combines the endpoint p-values. For directed graphs, each arc is evaluated only against its source node's outgoing fractional weight distribution; its source p-value is the primary lans_pvalue.

Parameters:

Name Type Description Default
network Network

Normalized simple graph to score.

 required
weight str

Edge attribute containing finite positive weights.

 'weight'
pvalue_aggregation str

How to combine endpoint p-values: min, max, or average.

 'min'
leaf_policy str

How degree-one endpoints contribute: zero treats the leaf endpoint as locally significant, while ignore ignores them during aggregation when another endpoint is available.

 'zero'

Raises:

Type Description
ConfigurationError

If a method parameter value is invalid.
ValidationError

If a required weight is missing, non-numeric, non-finite, zero, or negative.

compute_link_salience(network, *, weight='weight', distance_transform='inverse') ¶

Compute edge link salience from shortest-path trees rooted at each node.

Link salience is the fraction of root nodes whose shortest-path tree or shortest-path directed acyclic graph contains an edge. The default distance_transform="inverse" treats input weights as coupling strengths and uses 1 / weight as the shortest-path distance.

Parameters:

Name Type Description Default
network Network

Normalized simple graph to score. Directed graphs use outgoing shortest paths from each root and preserve arc direction.

 required
weight str | None

Edge attribute containing numeric weights. Pass None for unweighted unit-distance salience.

 'weight'
distance_transform str

inverse for strength weights or identity when weights are already shortest-path distances.

 'inverse'

Raises:

Type Description
ConfigurationError

If distance_transform is unknown.
ValidationError

If a configured weight is missing, non-numeric, non-finite, non-positive for inverse, or negative for identity.

apply_fraction(method_result, *, fraction, statistic=None, direction=None, tie_policy='include_all_ties', random_seed=None, drop_isolates=False) ¶

Select the top retained fraction of method statistics.

The method result's preferred_direction controls the ordering. Lower values are preferred for p-values and higher values are preferred for ordinary scores.

Parameters:

Name Type Description Default
method_result MethodResult

Method statistics to filter.

 required
fraction object

Requested retained fraction in the closed interval [0, 1].

 required
statistic str | None

Optional statistic column. Defaults to the method result's primary statistic.

 None
direction str | None

Optional ranking direction override. When omitted, the method result's preferred direction is used unless the method requires explicit direction.

 None
tie_policy str

One of include_all_ties, exact_stable, raise_on_tie, or random_seeded.

 'include_all_ties'
random_seed object | None

Required integer seed when tie_policy="random_seeded".

 None
drop_isolates bool

Whether edge extraction should remove isolated nodes after filtering.

 False

Raises:

Type Description
ConfigurationError

If the tie policy or statistic is invalid.
ValidationError

If the fraction or statistic values are invalid.
