Temporal input and aggregation¶

Import these names from netbone. See Aggregate temporal interactions for guidance on choosing time units and saving the aggregation settings.

from_temporal_edgelist(path, *, source='source', target='target', time='time', event_weight=None, delimiter=',', context=None, directed=False) ¶

Load repeated temporal interactions from a delimiter-separated file.

Each row represents one interaction occurrence and is retained for later aggregation. By default, reversed rows belong to the same undirected pair. With directed=True, source-to-target order defines an arc and reciprocal events are aggregated separately. Self-interactions are removed while their node labels remain part of the temporal network.

aggregate_temporal(temporal_network, config=None, *, weighting=None, evaluation_time=None, time_unit=None, snapshot_size=None, snapshot_origin=None, zero_weight_policy=None, **parameters) ¶

Aggregate temporal events into a static weighted Network.

Snapshot-based weightings use discrete snapshot ages. Persistent-memory weightings use exact elapsed ages without binning. No data-range normalization is applied.

Parameters:

Name Type Description Default
