Networks and loaders¶

Import these names from netbone. Use the loaders to create normalized networks and Network.to_original_graph() to obtain a NetworkX graph with input labels.

Network dataclass ¶

A normalized NetworkX graph with stable internal node and edge ids.

The stored graph uses integer node identifiers. Original node ids and edge attributes are preserved and result graphs are exported with original node ids.

directed property ¶

Return whether the normalized graph is directed.

edge_count property ¶

Return the number of edges in the normalized graph.

multigraph property ¶

Return whether the normalized graph is a multigraph.

node_count property ¶

Return the number of nodes in the normalized graph.

weighted property ¶

Return whether any edge has a weight attribute.

summary() ¶

Return a small JSON-compatible summary of the network.

to_dict() ¶

Return a minimal JSON-compatible summary of this network.

to_original_graph(*, node_ids=None, edge_ids=None, drop_isolates=False) ¶

Return a new NetworkX graph using original node ids.

Parameters:

Name Type Description Default
node_ids Iterable[int] | None

Optional internal node ids to include. When omitted, all nodes are eligible unless edge_ids and drop_isolates=True restrict them.

 None
edge_ids Iterable[int] | None

Optional internal edge ids to include. When omitted, all edges between included nodes are included.

 None
drop_isolates bool

Whether to omit nodes without retained incident edges.

 False

Raises:

Type Description
ValidationError

If unknown node or edge ids are requested.

to_undirected(graph_or_network, *, weight, reciprocal_merge) ¶

Return a deterministic undirected projection of a directed network.

One-way arcs become undirected edges without changing their attributes. When both arc directions exist, the selected finite numeric weight is combined with reciprocal_merge. Equal other attributes are retained; conflicting or missing values are stored as directional provenance on the projected edge.

Parameters:

Name Type Description Default
graph_or_network Graph | Network

Directed simple NetworkX graph or normalized network.

 required
weight str | None

Edge attribute to combine on reciprocal arcs, or None for an unweighted projection.

 required
reciprocal_merge ReciprocalMerge | None

Rule used for the selected weight on reciprocal arcs: "sum", "mean", "max", or "min". Must be None when weight is None.

 required

Raises:

Type Description
ValidationError

If the input is undirected or the merge rule is unsupported.
