Comparison, sweeps, and exports¶

Import these names from netbone. The plotting functions live in netbone.viz and require the optional viz extra at call time.

Comparison dataclass ¶

Compare multiple named backbone extraction results.

plot_data property ¶

Return plot-ready comparison data.

metric(name) ¶

Return one single-result metric for every result.

pairwise(metrics=None) ¶

Return tidy pairwise metric rows.

score_alignment(result_a, result_b) ¶

Return aligned method statistics for two compatible results.

spearman() ¶

Return pairwise Spearman score correlations where valid.

table(metrics=None) ¶

Return tidy single-result metric rows.

Sweep dataclass ¶

Immutable builder for parameter sweeps over pipelines.

describe() ¶

Return a reproducible summary of this sweep configuration.

filter(strategy, **parameters) ¶

Return a new sweep with the base filter configured.

grid(*, methods, filters) ¶

Add a Cartesian product of method and filter configurations.

Method and filter mapping values are parameter grids. Scalars are fixed values and finite sequences expand into grid values.

measure(metrics) ¶

Return a new sweep configured with requested metric names.

run() ¶

Execute the configured sweep and return tidy result tables.

score(method, **parameters) ¶

Return a new sweep with the base scoring method configured.

vary_filter(strategy=None, **parameter_grid) ¶

Add filter-parameter configurations to the sweep.

Grid values may be scalars or finite sequences. Changing only filter parameters reuses cached method scores during run().

vary_method(method=None, **parameter_grid) ¶

Add method-parameter configurations to the sweep.

Each distinct method-parameter combination gets its own score computation and cache entry.

SweepResult dataclass ¶

Results from executing a parameter sweep.

Successful configurations are available in results. Failed configurations are preserved in runs, failures, and table() rows instead of aborting the whole sweep.

failures property ¶

Return run rows for configurations that failed.

plot_data property ¶

Return plot-ready sweep tables without requiring plotting packages.

runs property ¶

Return one tidy status row per sweep configuration.

table() ¶

Return tidy metric rows for successful and failed configurations.

to_dict() ¶

Return a JSON-compatible summary of the sweep result.

Report dataclass ¶

A deterministic, JSON-compatible report payload.

Reports are generated entirely from computed values, metadata, warnings, and user-provided context already present in Netbone objects. They do not require or call an LLM provider.

to_dict() ¶

Return a JSON-compatible report representation.

to_markdown() ¶

Return a deterministic Markdown rendering of this report.

write_markdown(path, *, overwrite=True) ¶

Write this report as a UTF-8 Markdown file and return its path.

Parameters:

Name Type Description Default
path str | Path

Destination Markdown file path.

 required
overwrite bool

Whether an existing destination file may be replaced.

 True

Raises:

Type Description
ValidationError

If the destination is a directory, already exists while overwrite=False, or cannot be written.

save_experiment(subject, path, *, overwrite=False) ¶

Save a deterministic experiment bundle and return the bundle directory.

The bundle contains a manifest, deterministic report files, JSON payloads, and CSV tables suitable for inspection, sharing, and rerunning registered pipelines.
