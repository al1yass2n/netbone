Method catalog¶

Choose a method by the structure it measures and by the data it requires. All entries support simple undirected graphs subject to their attribute requirements. Directed support is shown below. A node method produces an induced subgraph after filtering. The other methods select edges.

Node measures¶

Method Weights Directed Suggested selection
Node Degree Weights ignored No 10% fraction
Node Strength Finite numeric No 10% fraction
Node Betweenness Positive when weighted No 10% fraction

The 10% defaults use fraction filtering, which can retain more when scores tie. Significance defaults use alpha 0.05 with correction set to "none". Check the individual method page before choosing a cutoff or reporting a statistical claim.

Try a method¶

The reference examples use this simple weighted graph. Run this block first, then run the block on a method page.

import networkx as nx
import netbone as nb

graph = nx.Graph()
graph.add_weighted_edges_from(
    [("A", "B", 8), ("A", "C", 3), ("B", "C", 5), ("C", "D", 2)]
)

Use nb.list_methods() to list registered names and nb.describe_method(name) to inspect metadata in Python.
