Pipelines and results¶

Import these names from netbone. A method produces a MethodResult and a filter produces a Selection. Running the full pipeline produces a BackboneResult.

Pipeline dataclass ¶

Immutable scoring and filtering configuration.

compute(graph_or_network) ¶

Compute method statistics without applying a filter.

describe() ¶

Return a compact description of the configured pipeline.

filter(strategy, **parameters) ¶

Return a new pipeline configured with a filtering strategy.

Parameters:

Name Type Description Default
strategy str | FilterCallable

Registered filter name or custom filter callable.

 required
**parameters object

Filter-specific parameters.

 {}

Raises:

Type Description
ConfigurationError

If the filter strategy is unknown.

from_dict(config) classmethod ¶

Restore a pipeline configuration produced by Pipeline.to_dict().

Only registered method and filter names can be deserialized. Custom filter callables must be recreated in Python and attached with Pipeline.filter(...).

Parameters:

Name Type Description Default
config Mapping[str, object]

Pipeline configuration mapping.

 required

Raises:

Type Description
ConfigurationError

If the configuration shape is invalid, a registered method or filter is unknown, or a custom callable filter is present.

Restore a registered pipeline configuration from a JSON file.

 required

Raises:

Type Description

If the decoded configuration is invalid.

A normalized selection produced by a filter.

Return counts describing this selection.

Return a minimal JSON-compatible summary of this selection.

BackboneResult dataclass ¶

Final result of applying a selection to a network.

edge_fraction property ¶

Return the fraction of original edges present in the backbone graph.

node_fraction property ¶

Return the fraction of original nodes present in the backbone graph.

statistics property ¶

Return the method statistics table used for this extraction.

Return a compact summary of graph retention and connectivity.

to_dict() ¶

Bases: NetboneError

Bases: NetboneError

Bases: NetboneError
