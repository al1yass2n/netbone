Netbone¶

Extract a smaller graph from a network, inspect why its edges or nodes were selected, and measure what the reduction preserves.

Run your first Python analysis Open the browser tutorial

Prepare a network¶

Load a CSV edge list, read GraphML, work with NetworkX directly, or aggregate time-stamped interactions before scoring.

Prepare graph inputs

Choose what to keep¶

Use a method that matches the structure you want to preserve. Apply a cutoff, a retention budget, a significance level, or the method's built-in selection.

Choose a method and filter

Evaluate a backbone¶

Compare retention and connectivity, examine overlap and rank agreement, or sweep settings to see where the result changes.

Compare backbones · Sweep settings

Share a run¶

Save settings, a deterministic report, and tables. Export the original and backbone graphs for inspection in other tools.

Save and reproduce an analysis

The Python package returns NetworkX graphs and pandas tables. The local web app uses the same analysis engine and ships with the package. If you already know the object or method you need, go to the Python reference or the method catalog.
